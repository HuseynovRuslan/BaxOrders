## 3. Təklif olunan axın

### 3.1 Əsas axın

```
Menyu → Aylıq hesabat  (Yığcam · Aylıq sifarişlər · serverin son ili · ada görə A–Z)
 ├─ Zolaq: üç rəqəm — əsas cavab + eyni anın «All» cavabı («Ümumi faktiki xərc» gələnə qədər «…»)
 ├─ Filtr: İl / Obyekt axtar (Enter) / Sifariş növü / Baxış / Sıfırla
 │     → URL (replace) → iki sorğu (All, sonra əsas); köhnə məlumat öz açarının adları ilə solğun və bağlı qalır
 ├─ «N / M obyekt» — filtrlərin altında daimi canlı bölgə, hər endə
 ├─ Başlıq: «Obyekt ↕» / «İl cəmi ↕» → URL `sort` (replace) → sorğusuz yenidən sıralama
 ├─ Dolu xana — adi klik və ya Enter → URL + `cell` (PUSH, öz işarəsi ilə) → sağ panel
 │     ├─ Esc / «Bağla» / fona klik / «Geri» → panel bağlanır (öz girişimizdirsə navigate(-1)), fokus xanaya
 │     ├─ «Sifarişə bax» → /orders/{id}?back=monthly (PUSH, { monthlyReport: true })
 │     │      └─ «Aylıq hesabat» və ya «Geri» → hesabat: il, axtarış, növ, baxış, sıra, panel; sətir görünür
 │     └─ «Obyektin sifarişləri» → /locations/{id} (PUSH) → «Geri» → hesabat + panel
 └─ Dolu xana — Ctrl/⌘/Shift/orta klik, kontekst menyusu → linkin öz işi: /orders/{id}?back=monthly yeni tabda
```

Boş (sifarişsiz) və gələcək ay xanaları klik qəbul etmir və hover-də dəyişmir (D-S3).

### 3.2 URL vəziyyəti

| Açar | Dəyərlər | Yoxdursa | Kim yazır | Tarixçə |
|---|---|---|---|---|
| `year` | `2026` | serverin son ili | İl seçimi; xana açılanda da (URL-də yoxdursa) | `replace`; xananın girişində `push`-un içində |
| `search` | mətn | axtarış yoxdur | axtarış formu (Enter) | `replace` |
| `scope` | `OutsideMonthly`, `All` | `Monthly` | Sifariş növü | `replace` |
| `view` | `standart` | Yığcam | Baxış | `replace` |
| `sort` | `ad-azalan`, `cem-azalan`, `cem-artan` | ada görə A–Z (API sırası) | sütun başlığı; `lg`-dən aşağı «Sıralama» | `replace` |
| `cell` | `<locationId>-<MM>`, məs. `21-06` | panel bağlıdır | xana | **`push`**, `state: { reportCell: true }` |
| `back` | `monthly` | — | yalnız sifariş linki (dəyişmir) | — |

- Tanınmayan dəyər defolta düşür (bu günkü `scope` qaydası, `MonthlyReportPage.tsx:36-37`).
- `view` və `sort` dəyərləri idarəetmə panelinin qaydası ilə azərbaycanca, ASCII ilə (`analytics/dashboardView.ts:30-35`:
  `sade`, `etrafli`).
- `cell` tapılmırsa (obyekt cavabda yoxdur, ay sifarişsizdir, ay gələcəkdir) panel açılmır, `cell` `replace` ilə çıxır.
- Xana açılanda URL-də `year` yoxdursa, ekrandakı il də yazılır: paylaşılan link sonra başqa ilin xanasını açmasın.
- «Sıfırla» `search`, `scope`, `view`, `sort`, `cell`-i silir, `year`-i saxlayır (02 §10 [Fərziyyə]).

  bir-birinə zidd olmaması üçün.
- Hamısı `AbortController` ilə; köhnə cavab yeni açarın yerinə yazılmır (bu günkü `lastKey` qaydası).
- Heç bir halda brauzer iki rəqəmi toplayıb «Ümumi faktiki xərc» yerinə qoymur.

### 3.4 Panelin açılıb-bağlanması

Model `OrderDetailPage.tsx:139-182`-dəki məhsul çəkməcəsidir (19.2).

1. **Açılış.** Dolu xanaya **adi klik** (sol düymə, modifikatorsuz) və ya fokusda **Enter** → `preventDefault`, URL-ə
   `cell` (+ lazımsa `year`) **push**, `state: { reportCell: true }`. Ctrl/⌘/Shift/Alt, orta düymə, kontekst menyusu
   linkin öz işidir — `href` (`/orders/{id}?back=monthly`) dəyişmir (AC-11; qayda `interaction.ts:25-46` ilə eyni).
2. **Bağlanma** — Esc, «Bağla», fona klik (panel oxunandır — `dismissOnBackdrop` açıq, 17.2), brauzerin «Geri»si.
   Giriş bizimkidirsə `navigate(-1)`; deyilsə (yapışdırılmış link, yeniləmə) `cell` `replace` ilə silinir. Bir girişdə
   bir bağlanma: iki tez Esc və ya klik səhifədən çıxarmır.
3. **Fokus.** Açılanda — «Bağla» (`Modal.tsx:83-88`). Bağlananda — panelin təsvir etdiyi xananın linki (`cell` açarı
   ilə tapılır; Safari linki klikdə fokuslamadığı üçün açanın `activeElement`-inə güvənilmir): əvvəl
   `scrollIntoView({ block: 'nearest', inline: 'nearest' })` — bu, xananın `scroll-margin`-ını və qutunun
   `scroll-padding`-ini nəzərə alır (§6.3), ona görə xana üzən başlığın və sabit sütunların altına düşmür — sonra
   `focus({ preventScroll: true })`. Xana tapılmırsa — səhifənin `h1`-i.
4. **`cell` ilə gəliş** (yapışdırılmış link, yeniləmə, «Geri» ilə qayıdış): cədvəl gəldikdən sonra həmin sətir
   (`lg`-dən aşağı — kart) `block: 'center'` ilə görünən yerə gətirilir, sonra panel açılır. Drawer-in içindəki klik
   sətrin id-sini tapa bilmir (`useScrollMemory.ts:86` — anchor `null`), ona görə sətri `cell` göstərir.
5. **Forward** bağlanmış girişi qaytaranda panel yenə açılır və yenə bağlana bilər.
6. **Arxa səhifə** panel açıq olanda sürüşmür və yerindən tərpənmir (`Modal.tsx:67-75`); fon açıqdır (19.1).

### 3.5 Sıralama, görünüş, sıfırlama, köhnə məlumat

- **Sıralama** brauzerdə, API-nin öz rəqəmləri ilə — hesablama deyil; yalnız `tbody`-nin sətirləri; «Cəmi» sonda;

- **Köhnə məlumat (DK-04).** `year` / `search` / `scope` dəyişəndə ekran **son uğurlu cavab cütünü** (əsas + «All»)
  öz açarı ilə — `shownKey = { year, scope, search }` — saxlayır, 60% solğun və `inert` göstərir (klik və fokus
  almır). **Bütün sözlər və rəqəmlər `shownKey`-dəndir:** zolağın etiketləri (`scopeAmountLabels[shownKey.scope]`
  və §6.8.1-in qalan sütunları), «Ümumi faktiki xərc», sayğaclar, axtarış qeydi, «N / M obyekt», «Cəmi» /
  «Cəmi — bütün obyektlər», cədvəlin başlığı. **İdarəetmə elementləri URL-i göstərir:** il seçimi URL-dəki ili
  (yoxdursa `shownKey`-in ilini), axtarış sahəsi URL-dəki mətni, «Sifariş növü» URL-dəki növü. Görünüş və sıra sorğu

- **Bu gün nə var, V2 nəyi dəyişir (açıq):** bu gün 1280-də 12 ayın hamısı görünür, amma səhifə ~13–30 px yana
  sürüşür (il sütununun sonu kəsilir) və beşrəqəmli məbləğlər ~3 px üst-üstə düşür (§2.3). V2-də səhifə sürüşmür və
  məbləğlər arasında ≥ 6 px var — bunun qiyməti: 12 px-də ~2 ay qutuda gizlənir (Yanvar), E-də ~1 ay (gələcək aylar).
  Bütün 12 ay 1280-ə yalnız məbləğlər bitişəndə sığır — bunu təklif etmirik.
- **Səhifə heç vaxt yana sürüşmür** (AC-14). Qutu `overflow-x: auto`; obyekt sütunu solda, il sütunu sağda qutunun
  içində yapışqandır.
- **Seçim A — üzən başlıq.** Cədvəlin öz `thead`-i semantika üçün yerində qalır. **Yalnız** `thead` 72 px xəttindən
  yuxarı çıxanda (IntersectionObserver, `rootMargin: -72px 0 0 0`) onun **görünən surəti** (`aria-hidden`) 72 px-də
  (`top-18`) görünür: eyni `table-fixed`, `colgroup`, `min-w`, `border-separate`, qutunun `clientWidth`-i; qutunun
  `scrollLeft`-i ilə sinxron sürüşür; en dəyişəndə (o cümlədən panel açılanda Windows skrolbarı itəndə) ResizeObserver
  yenidən ölçür. Surət köhnə məlumatda solğun və `inert`-dir; gələcək ayın ştrixi və aktiv sıra əsl başlıqla eynidir.
- **Cədvəlin ortasında yana keçid (DK-02-1):** surətin altında **12 px-lik nazik sinxron sürüşmə zolağı** var — yalnız
  aylar sahəsində (sabit sütunların arasında), yalnız qutu həqiqətən sürüşəndə; siçanla dartılır və basılır,
  qutu ilə iki tərəfli sinxrondur; `aria-hidden` (qutunun öz skrolbarının vizual surətidir). Üstəlik: trackpad / Shift+çarx
  istənilən sətrin üstündə işləyir; klaviatura ilə Tab xanaya keçəndə qutu özü sürüşür; cədvəlin yuxarısında — kartın
  başlığında — «‹ Əvvəlki aylar» / «Sonrakı aylar ›» düymələri və görünən aralıq (`formatMonthRange`).
- **İlk mövqe** §4.1-in cədvəlinə görə; sürüşmə ay sərhədlərinə «yumşaq» yapışır (`scroll-snap-type: x proximity`,
  `scroll-padding-inline` = sabit sütunlar).
- Mexanizmin alternativləri (B, C, D) və qiymətləri §9.1-də; sıxlıq §9.2-də. Seçim sahibindir (§11).

### 6.3 Yapışqan başlıq, sabit sütunlar, üfüqi sürüşmə, fokusun görünməsi (DK-01)

- **Qutu:** `overflow-x: auto` bütün masaüstü enlərində; cədvəl `table-fixed`, `w-full`, `min-w` §4.1.
- **Sabit sütunlar:** obyekt (`sticky left-0`) və il (`sticky right-0`) qutunun içində; arxa fonları var; daxili
  kənarda 1 px `outline-variant`.
- **Başlıq:** Seçim A (§4.3) — 72 px-də (`top-18`) üzən surət, yalnız əsl `thead` 72 xəttindən yuxarıda olanda.
  **z-qatları:** tətbiq başlığı `z-20` > üzən başlıq `z-10` > `thead` künc `z-[3]` > `thead` `z-[2]` > `tbody` sabit
  xanaları `z-[1]` (bu günkü sıra; test §10.3 #12).
- **Fokus heç vaxt örtülmür — mexanizm:**
  1. Qutuda **`scroll-padding-inline: 120px 88px`** (E-də 1440-dan aşağı `120px 84px`) — sabit sütunların eni. Fokus
     qutudan kənardakı ay xanasına keçəndə brauzer qutunu elə sürüşdürür ki, xana obyekt və il sütunlarının arasında
     tam görünsün (sağa Tab-da «İl cəmi»nin altına düşmür).
  2. `tbody` və `tfoot` daxilindəki hər fokuslanan elementdə (obyekt linki, xana linki) **`scroll-margin-top: 124px`**
     (72 tətbiq başlığı + 40 üzən başlıq + 12 sinxron zolaq) və `scroll-margin-bottom: 16px`. Yuxarıdan gələn fokus
     (Shift+Tab, Esc-dən sonrakı `block: 'nearest'`) elementi üzən başlığın altına qoyur.
  3. Əsl `thead`-in sıra düymələrində və cədvəldən yuxarıdakı hər fokuslanan elementdə (filtrlər, «Yenidən cəhd et»,

     `thead` artıq xəttdən yuxarıda olmadığı üçün surət gizlənir — fokus halqası heç nəyin altında qalmır.
  4. Surətin sıra düymələri siçanla işləyir; basılanda sıra dəyişir və fokus **əsl** düyməyə keçir
     (`focus({ preventScroll: true })`) — fokus `aria-hidden` bölgədə qalmır (DK-23-3). Surətin düymələri `tabindex="-1"`.
- **Klaviatura ilə sürüşmə:** qutunun öz rolu və Tab dayanacağı yoxdur — içindəki linklər klaviaturanı təmin edir
  (axe `scrollable-region-focusable` keçir); fokus xanadadırsa ox düymələri qutunu sürüşdürür.
- **İlk mövqe, ay düymələri, sinxron zolaq** — §4.3. Panel bağlananda seçilmiş xana yuxarıdakı qayda ilə görünən yerə
  gəlir (§3.4-3).

## 8. Əlçatanlıq

- **Klaviatura sırası:** səhifə başlığı → (zolaqda yalnız «Yenidən cəhd et», olanda) → İl → Obyekt axtar → Sifariş növü
  (3) → Baxış (2) → Sıfırla (görünəndə) → (kartın başlığında ay düymələri, qutu sürüşəndə) → «Obyekt» və «İl cəmi» sıra
  düymələri → hər sətir: obyekt linki, dolu xanalar soldan sağa. Boş/gələcək xanalar dayanacaq deyil. ~290 dayanacaq —
  axtarış qısa yoldur; ox düymələri ilə «grid» sonrakı mərhələdir (§9.10).
- **Görünən fokus:** hər interaktiv elementdə 2 px `primary` halqa; heç bir fokus tətbiq başlığının, üzən başlığın və
  sabit sütunların altında qalmır — mexanizm §6.3 (`scroll-padding-inline`, `scroll-margin-top` 124 / 72, surətin
  yalnız `thead` yuxarıda olanda görünməsi, fokusun əsl düyməyə yönəldilməsi).
- **Cədvəl semantikası:** `table` görünən `h2`-yə `aria-labelledby` ilə; `th scope="col"` / `scope="row"`; `aria-sort`
  yalnız aktiv sütunda (defolt «Obyekt» `ascending`); üzən başlıq və sinxron zolaq `aria-hidden`.
- **Xana:** link, `aria-haspopup="dialog"`, accessible name — bugünkü `describe()` cümləsi. İşarələr `aria-hidden`.
- **Dialoq:** `role="dialog"`, `aria-modal`, `aria-labelledby` (obyektin adı), `aria-describedby` (ay · növ); fokus
  tələsi, Esc, fokusun qayıdışı. Açıq `<select>` siyahısında Esc-i Chrome özü udur (Modal-ın `defaultPrevented` qaydası
  burada işləmir — brauzerdə yoxlanır).
- **Canlı bölgələr:** «N / M obyekt» — **daimi** `role="status"` (mətn dəyişir, bölgə yaranıb-itmir); «Yüklənir…» —
  `role="status"`; xəta — `role="alert"`; «Ümumi faktiki xərc alınmadı.» — `role="status"`.
- **Rəng yeganə daşıyıcı deyil:** istiqamət — +/−, ▲/▼, «xərc artıb/azalıb»; status — ✓ ⏳ ↩ simvolları + söz; ⚠ simvolu;
  gələcək ay — ştrix (≥ 3:1) + AN; seçilmiş seqment — ağ fon + halqa + yarımqalın + `aria-pressed`.
- **Kontrast:** mətn ≥ 4,5:1, qeyri-mətn ≥ 3:1 (`04-visual.md` §4; Tailwind 4 dəyərləri ilə).
- **Toxunma hədəfləri (`lg`-dən aşağı):** filtrlər, seqmentlər, «Sıfırla», «Yenidən cəhd et», kartın ay xanası, obyekt
  adı, panelin footer düymələri (o cümlədən «Bağla») ≥ 44 × 44 px. Modal-ın X-i 24 px qalır (ortaq; ayrıca təklif).
- **Hərəkət:** ay düymələri, sinxron zolaq və sətrə qayıdış `prefers-reduced-motion`-da animasiyasız.
- **Böyütmə:** 200% zoom-da (1440 → 720 CSS px) kart görünüşü; yana sürüşmə yoxdur.

əsaslı testlər `table`/`link`-ə bağlıdır və meyarlarda tələb yoxdur. Sonrakı mərhələ.

### 9.11 Planşet

**Tövsiyə: kartlar, ay şəbəkəsi 640–1023 px-də 6 sütun.** Alternativ: 3 sütun (bu gün) — iki dəfə hündür; cədvəl +
yana sürüşmə — 720 px-də ~4 ay.

### 9.12 Telefonda «Baxış»

**Tövsiyə: tətbiq olunur.** Alternativ: gizlədilir — `view=standart` linki telefonda işləməzdi.

### 9.13 Sıralama UI

**Tövsiyə: masaüstündə başlıq düymələri, aşağıda select.** Alternativ: hər yerdə select — cədvəl konvensiyası itir.

### 9.14 «Sıfırla»

**Tövsiyə: sıranın sonunda, yeri həmişə ayrılmış; yalnız lazım olanda görünür; sonra fokus axtarışa.** Alternativ:
həmişə görünən deaktiv düymə — sabit, amma «heç nə etməyən düymə» (D-S3 ruhu).

### 9.15 Yenilənmə

**Tövsiyə: köhnə məlumat öz açarının sözləri ilə, solğun və `inert`.** Alternativ 1: skelet (bu gün) — səhifə tullanır.
Alternativ 2: köhnə məlumat işlək — səhv adla rəqəm və səhv panel.

### 9.16 URL dəyərləri

**Tövsiyə: `view=standart`, `sort=cem-azalan|cem-artan|ad-azalan`.** Alternativ: ingiliscə — kodda ikinci qayda.

### 9.17 «All» sorğusu

**Tövsiyə: hər əsas sorğu ilə birlikdə, ondan əvvəl** (DK-13). Alternativ: il üzrə yaddaş — bir sorğu az, amma üç
rəqəm iki fərqli anın cavabı ola bilər.

### 9.18 Əfsanənin yeri

**Tövsiyə: cədvəlin üstündə, ekranda.** Alternativ 1: altında (Figma) — 27 sətirdən sonra. Alternativ 2: açılan
«İşarələr» — 1280-də ~18–36 px qazandırır, amma bugünkü «işarələr ekranda» qaydasını pozur.

## 11. Açıq suallar və [Fərziyyə]lər

### 11.1 Sahibə suallar

Adlar: **S-1 … S-4** (bir rəqəmli) — sahibə suallardır; **S-01 … S-04** (iki rəqəmli) — `02-requirements.md`-nin
«Should» tələbləridir (məs. UX-29-dakı S-04 = `hasPrice` süzgəci).

**S-1 · Axtarış və yuxarı rəqəmlər (02-də açıqdır).** Dizayn A variantına qurulub: rəqəmlər bütün obyektlər üzrə qalır,
axtarış aktiv olanda bu yazılır.

**S-2a · Cədvəl yana sürüşəndə ay adları necə görünsün? (B-07)** Səhifənin özü heç bir halda yana sürüşməyəcək.
- **A (tövsiyə):** ay adları aşağı sürüşəndə ekranın yuxarısında qalır, aylarla birlikdə yana hərəkət edir, altında nazik
  sürüşmə zolağı olur — cədvəlin ortasında da yana keçmək olur. Qiyməti: proqramçı üçün ən çox iş, yoxlama brauzerdə.
- **B:** cədvəlin ekran boyda öz qutusu və öz sürüşməsi olur; ay adları və yana sürüşmə zolağı həmişə görünür. Sadədir,
  amma səhifədə iki sürüşmə olur: siçan cədvəlin üstündə olanda səhifə yox, cədvəl sürüşür.
- **C:** ay adları yapışmır — aşağı sürüşəndə ekrandan çıxır (əvvəl bildirdiyiniz nasazlıq qayıdır).
- **D:** aylar hissə-hissə (məs. 6 ay) göstərilir, düymə ilə dəyişir; il bir ekranda görünmür.

**S-2b · 1280 px-lik laptopda rəqəmlərin ölçüsü.** Bu gün 1280-də 12 ay görünür, amma səhifə azca yana gedir və
beşrəqəmli məbləğlər bir-birinə toxunur. V2-də səhifə yana getmir və məbləğlər arasında boşluq var; buna görə bütün 12 ay
1280-ə sığmır. Seçin:
- **«Rəqəmlər 12 px» (bu günkü ölçüyə yaxın):** rəqəmlər bu gün kimi oxunur və məhsulun «rəqəm ən azı 12 px» qaydasına
  uyğundur; 1280-də ~10 ay görünür, Oktyabrda açılışda **Yanvar görünmür** (sola sürüşdürmək lazımdır).
- **«Rəqəmlər 11 px» (E, tövsiyə):** rəqəmlər **bu gündən bir az kiçik və incədir** və 12 px qaydasından istisnadır (yalnız
  masaüstü cədvəldə, 1024–1439 px); bunun əvəzinə 1280-də ~11 ay görünür — Oktyabrda **Yanvar–Oktyabr görünür**, yalnız
  hələ başlamamış Noyabr–Dekabr sağda qalır; 1366-da 12 ay.
1440 və daha geniş ekranda hər ikisində 12 ay görünür, rəqəmlər 12 px-dir. (Mətn DK-28 ilə düzəldilib.)

**S-3 · Cədvəldə «Təsdiqlənib» işarəsinin rəngi.** İşarə məhsulun öz simvoludur (✓). Cədvəldə **boz** ✓ (tövsiyə — yaşıl
rəng cədvəldə yalnız «xərc azalıb» desin), yoxsa hər yerdəki kimi **yaşıl** ✓? Paneldəki nişan hər halda yaşıldır.

**S-4 · Zolaqda daimi cümlə.** Hesabat hər obyekt+ay üçün son sifarişi təsdiqlənib-təsdiqlənməməsindən asılı olmayaraq
sayır (bu gün Oktyabrın 24 sifarişi təsdiq gözləyir). Rəqəmlərin altında həmişə bu cümlə yazılsınmı: «Təsdiqlənməmiş
sifarişlər də daxildir; təsdiq gözləyənlər cədvəldə ⏳ ilə işarələnib.» (və ya daha qısa: «Təsdiq gözləyən sifarişlər də
daxildir — cədvəldə ⏳ ilə işarələnib.» — bu, qaralama və düzəlişə qaytarılan sifarişləri adlandırmır).

### 11.2 [Fərziyyə]lər

- Windows Chrome-un skrolbarı 15–17 px-dir; hesablar S = 17 üçün də verilib.
- Rəqəm enləri şrift fayllarından ölçülüb (Geist, Inter — Google Fonts; ₼ və simvollar — Segoe UI / Segoe UI Symbol);
  brauzerin render-i (hinting, yuvarlaqlaşdırma) ±1 px dəyişə bilər — 1440-da Yığcamın ehtiyatı 1 px-dir.
- Görünən sahə: 1280×800 → ~667 px, 1440×900 → ~767 px, 1024×768 → ~635 px (tapşırıq paneli 48, Chrome ~85).
- ⏳ + U+FE0E Windows Chrome-da monoxrom simvol kimi çıxır; çıxmasa ehtiyat ikon (§6.2.3).
- B-07-nin 2026-09-27 ölçmələri 256 px sidebar ilə edilib; 260 px-də 1280-də ~13 / ~30 px gözlənilir.
- Bu gün 1280-də beşrəqəmli qonşu məbləğlərin ~3 px üst-üstə düşməsi hesabdır, brauzerdə görülməyib.
- `top-16` ilə 8 px-lik örtülmə yalnız başlıq xanasının üst boşluğunu örtür — görülməyib.
- Ay sütununda altırəqəmli məbləğ hazırda yoxdur (şirkət ayının ən böyüyü ~71 min).
- Sahibin laptopunun eni məlum deyil (1280, 1366, 1440, yoxsa 125% miqyasda 1536).
- Paneldə sətir səhifəsi 50-dir (02 §10).
- Panel açılanda `Modal` səhifənin skrolbarını gizlədir (`body overflow: hidden`), Windows-da arxa səhifə 17 px enlənir;
  üzən başlıq ResizeObserver ilə yenidən ölçülür. `scrollbar-gutter: stable` bunu tam həll edər, amma qlobaldır.
